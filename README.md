# 🛍️ Brand's Wardrobe Kids Corner - Official Store

A modern, fast, and responsive E-Commerce web application built for **Brand's Wardrobe Kids Corner**. This platform allows customers to seamlessly browse winter collections, select sizes, add items to a cart, and place direct orders via WhatsApp.

---

## ✨ Features

- **Interactive Shopping Bag:** Add items, view summary, and manage quantities in real-time.
- **Smart Size Selection:** Choose sizes (2-3Y to 10-12Y) directly before ordering.
- **Dynamic Category Filters:** Easy navigation between Boys Tracksuits, Girls Tracksuits, and Cargo/Baggy Pants.
- **1-Click WhatsApp Checkout:** Automatically calculates total prices and sends formatted order details directly to the official business WhatsApp.
- **Official WhatsApp Channel Integration:** Instant link for customers to join and watch regular product showcase videos.
- **Mobile First & Responsive:** Clean UI optimized for mobile shoppers.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel
